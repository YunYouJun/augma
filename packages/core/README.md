# @augma/core

Framework-independent Augma tokens and CSS. Import `@augma/core/tokens.css` for variables only or `@augma/core/style.css` for complete component styles. No Vue runtime dependency and no global element reset.

Use `.dark` or `data-agm-theme="dark"` on the document root for dark mode. Override namespaced `--agm-*` variables for custom themes. See https://augma.yunyoujun.cn/design/.
