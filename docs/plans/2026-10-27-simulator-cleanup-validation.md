# 模拟器专项清理验收

日期：2026-10-27。状态：已实现设备与运行时扫描、匿名 AI 建议、逐项选择与原生确认执行，并完成构建和基础验收。

## 已实现范围

- 入口：系统监控 → 清理磁盘与内存 → 模拟器专项清理。无需 Mole。
- 固定使用 `/usr/bin/xcrun simctl list devices --json` 与 `simctl runtime list --json`。按设备数据和共享运行时映像分别展示容量、状态、最后使用时间及默认设备集依赖数，按容量排序；未知容量不计入已知估算。
- 仅明确关闭的设备可执行；默认设备集仍有运行或未知状态的设备时禁止删除运行时。运行时有默认设备集关联设备、未知状态或无法验证删除能力时只供查看。
- 不扫描其他设备集。运行时是全局资源，确认页明确 Xcode 预览、CI、自定义设备集尚未核对，必须另外勾选已检查并关闭相关模拟器；后端也验证该声明，未确认的混合批次不会先删除设备。
- 确认绑定扫描 ID 和所选对象，五分钟有效、单次消费。每项执行前重新查询身份、容量、状态和依赖，并在查询返回后再次核对时效。不会自动关机、批量删除全部设备或直接删除目录。
- 删除后有限重查系统清单；回执区分已删除、跳过、失败、等待系统完成。另记录同卷可用容量差值，不把估算或命令退出成功当成实际释放空间。
- AI 仅收到最多 20 项匿名编号、类别、大小、年龄、状态与依赖数，以及默认设备集范围声明。严格校验回复结构、已有且可建议的编号；不发送名称、UUID、路径或报告，不自动勾选或执行。离开、取消或配置变化会丢弃迟到结果。

## 验证

```sh
AUGMA_TEST_SIMULATOR_SCAN=1 AUGMA_TEST_APPLE_ICONS=1 \
swift test --package-path apps/mac \
  --filter 'SimulatorCleanupTests|ApplicationCleanupTests|AppleIconTests' \
  -Xswiftc -Xclang-linker -Xswiftc -isysroot \
  -Xswiftc -Xclang-linker -Xswiftc "$(xcrun --sdk macosx --show-sdk-path)"
```

提交前将 Git 暂存树导出到独立目录，以上命令在仅包含本次改动的 macOS 15 目标快照中构建并通过 38 项测试：23 项模拟器测试、13 项公共图标测试、2 项应用退出身份保护测试。未依赖工作区尚未提交的 Homebrew、应用市场、通用文件扫描、网络监控或打包配置。

模拟器测试包含本机只读扫描，确认保留的 5 台设备和 2 套运行时；删除测试均使用注入执行器，未触碰真实设备。覆盖未知容量和状态、依赖保护、确认过期及查询期间过期、状态变化、每项复查、混合批次范围确认、固定命令、部分失败、异步删除、AI 匿名与迟到回复，以及跨自然日的小时级使用间隔。列表和确认清单已在窄/宽、深/浅色渲染检查。图标测试验证系统设备图片、应用图标、Finder 的 FNDR 包类型和缓存失效；应用退出测试验证 PID、路径、启动时间与宿主身份，未退出真实应用。

本次提交的独立入口由 `SimulatorCleanupPanel` 承载，复用 `ApplicationCleanupSection` 和公共图标模块。工作区的通用清理面板继续复用同一模拟器 Store，不纳入此提交。

此前完整工作区的构建、签名、启动及主窗口检查成功。真实应用中已打开专项面板，扫描到保留的 5 台设备和 2 套运行时；运行设备及有关联设备的运行时均不可勾选，默认选择为空。

通过已配置的 AI 运行时真实发送匿名摘要并收到建议，确认返回后没有自动选择任何项目。随后手动选择一个已关闭设备，核对原生确认清单并取消，取消选择后恢复零选中状态，没有执行删除。首轮模型将不足 24 小时理解为“今天”，因此将摘要改成经过的整小时，并在指令中明确不得据此推断自然日；本地日期仍显示系统提供的真实时间。
