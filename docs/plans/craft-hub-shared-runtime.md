# Craft Hub 按需共享运行时接入

日期：2026-11-04。状态：架构方向已确认，待实施。目标是 Electron 完全退出后，Augma 仍能通过共享连接器直接发送到小米云；本机草稿和摘要缓存继续独立工作。

权威设计位于 Craft Hub 仓库的 `docs/plans/on-demand-shared-runtime.md` 与 ADR 0015。本文只记录 Augma 的接入职责，不复制供应商实现。

## Augma 拥有的行为

- 继续使用 `WorkspaceStore` / `WorkspaceFile` 保管输入和本机恢复数据，菜单与浮窗编辑同一个草稿。
- 通过新的 `CaptureSending` Adapter 发现共享目标、开始显式登录、预览/确认、提交并查询持久回执。稳定 attempt ID 与账号/目标绑定在发送前落盘。
- 发送或主动查询时取得短期运行时租约，完成后释放；展开菜单、编辑草稿和展示缓存不启动后台运行时。不以定期轮询保持连接。
- 只接收不透明连接 ID、账号显示标签、revision、能力和回执；不接收 Cookie/refresh token，不读取 Craft Hub 私有资料，也不安装另一份云插件。
- 断开 Augma 配对只撤销客户端访问；登出共享云账号是影响其他客户端的独立操作。Augma 自身账号、项目所有者与云服务账号互不替代。
- Electron 不运行但 Craft Hub 已安装、后台入口已授权时，直接连接被按需激活的共享 worker；无需先打开 Electron。首次设置缺失或服务禁用时说明原因并保留本机草稿。
- 断网/运行时不可用时显示“尚未发送”；结果未知时保留尝试身份，不因重启、重新点击或网络恢复自动创建第二条笔记。

## 共享侧拥有的行为

Craft Hub 提供唯一的业务运行时、供应商插件、账号连接、系统凭据 Adapter、登录窗口和提交日志。macOS 控制进程由系统按需启动，管理一个独立 Node worker；登录时才启动隔离的原生账号 UI。没有工作台会话、操作或交互授权后，宽限到期退出全部相关进程。

小米插件目前只有读取和本机备份，没有创建/上传。须先验证真实写入路径及回执，再向 Augma 声明可用目标。新小米能力不增加 Augma 专属 Cookie 表单或供应商 SDK。

现有 `MicrosoftToDoStore` / `NativeCaptureSender` 保留原有账号和待发状态，待共享目标完整验收后显式迁移对应目标；不自动合并两套登录。新云能力统一接共享路径，原生备忘录继续使用本机 Adapter。Agent 项目只读连接和摘要文件均不因此获得写权限。

## 接入验收

1. 一个发行版/资料范围只有一个 worker，两个客户端并发发送不会各启动一份。
2. Electron 已退出时，完成目标选择、共享登录、发送及回执显示；取消登录不丢草稿。
3. 登录只显示同一份原生账号 UI；跨账号、地区或连接 revision 变化会作废旧审阅。
4. 发送时退出/重启 Augma，恢复后查同一尝试；未知结果不重发，不把“打开应用”当成交付成功。
5. 仅查看缓存或编辑草稿时无 worker；操作完成和宽限结束后，Broker、Node、插件子进程及登录 WebKit 均已退出。
6. 与现有默认记录目标、菜单栏、浮窗、草稿、已发送回执及本机备忘录做回归；保留真实资料、独立候选及按进程身份核实的清理证据。

当前仅交付设计，不变更源码、启动系统后台项或向真实账号写入测试笔记。当前 Augma 最低系统仍为 macOS 26。
