# 0.1 からの移行

0.2 は互換性のない変更を含む作り直しです。アップグレードの前に、プロジェクトが旧コンポーネント、内部パス、スタイルのプリセットにどう依存しているかを確認してください。

| 旧来の使い方 / 機能 | 0.2 での使い方 |
| --- | --- |
| `app.use(augma)` | `import { AgmButton } from 'augma'` などの名前付きインポート |
| 旧 SCSS / UnoCSS プリセット | `import 'augma/style.css'` |
| ワークスペース内部のコンポーネントパス | `augma` の公開エクスポート、または Registry から自分のプロジェクトにコピー |
| Card | AgmPanel。内容に合わせてスロットを組み合わせます |
| Clock / Menu / BottomMenu | 基本コンポーネントで組み立てます。[ショーケースを見る](/ja/showcase/) |
| Button / Input / Select などの旧 Props | 新しいコンポーネント API を確認してください。互換性は保証されません |
| コンポーネントパッケージに混在していたカメラと Babylon | 独立した [AR デモ](/ja/guide/ar) |
| TensorFlow / 物体検出の実験 | 初回リリースで削除。安定した機能としては公開していません |

フレームワークに依存しないスタイルには `@augma/core` を使います。Vue パッケージには Vue 3.5 以降が必要で、複雑な振る舞いは Reka UI が提供します。初回リリースには、グローバルなコンポーネント登録プラグインも React パッケージもありません。

ドキュメントとショーケースは `augma.yunyoujun.cn` に統一し、`augma.yyj.moe` の Cloudflare Pages デプロイでも同じ内容を提供します。旧ドメインの移行は実際のホスティングの切り替えによるもので、npm パッケージのアップグレードで自動的に完了するものではありません。
