# AR デバイスシミュレーター

<a href="/ar/" target="_self">デバイスシミュレーターを開く</a>。デバイスを装着しなくても、カメラをオンにしなくても、Augma の空間レイヤーとアプリの操作を体験できます。

## シミュレーションビューを探索する

ビューは [Augma のオリジナルサイト](https://augma.elpsy.cn/) を踏襲しています。上部に時計と白いライン、下部に 9 つの円形アイコンが並びます。カメラを使わないときは、現在の空間シーンが動くレイヤーとして背景に映り、オリジナルの無地のグレーに戻すこともできます。アプリをクリックするとフローティングウィンドウが開き、もう一度クリックするか Escape で閉じます。カメラをオンにすると、現実の映像が背景になります。

下部には順に、映像の反転、天気、HUD 表示、サウンド、空間、カメラ、ナビ、GitHub、コンポーネントのドキュメントが並びます。右上のシステムメニューには、フルスクリーン、カメラの切り替え、テーマ、設定、通知、デバイスの操作があります。左上のマイクを押すと[音声コマンド](#音声コマンドと-deepseek-アシスタント)が開きます。

インターフェースは简体中文、English、日本語に対応しています。このドキュメントから開くと、読んでいる言語をそのまま引き継ぎます。直接開いた場合は前回の選択を使い、初回はブラウザの言語に従います。「設定 → 言語」で切り替えられ、選択は現在のブラウザに保存されます。音声コマンドを実行すると、結果を現在の言語で読み上げます。ブラウザが音声合成に対応していない場合はテキストだけを表示します。「音声読み上げ」は設定でオフにできます。

| アプリ | 試せる操作 |
| --- | --- |
| 天気 | 都市を切り替えてサンプルの気温を表示（リアルタイムの天気ではありません） |
| 空間 | 空中庭園 / シティウォークの切り替え、スキャンとキャンセル、アンカーの固定 / 解除、シーン内の場所のクリック |
| ナビ | 目的地の選択、色分けされたルートの切り替え、模擬ナビの開始、到着まで一歩ずつ進める、ナビの終了 |
| サウンド | ローカルで合成した和音の再生、一時停止、曲の切り替え、再生位置と音量の調整 |
| 通知 | この体験中の操作履歴を表示。開くと既読になり、履歴は消去できます |
| 設定 | 言語、パネルの不透明度、ダークビュー、集中モード、映像の反転、音声読み上げ、DeepSeek アシスタント、シーン背景、奥行きアニメーション、カーブビュー、キーボードショートカット、初期設定に戻す |

システムメニューの「デバイス」では、スタンバイ、起動、切断、再接続ができます。スタンバイまたは切断すると、スキャン、ナビ、サウンド、カメラ、空間 AR が止まります。下部の目のアイコンでアプリと空間レイヤーを一時的に隠し、もう一度クリックすると元に戻ります。

地図、場所、距離、スキャン結果はすべてシミュレーションで、位置情報、実環境の認識、リアルタイムの交通情報を表すものではありません。インターフェースは Augma の現実に重なるレイヤー、円形のアプリコントロール、浮かぶルートを参考に、操作できる SVG で実装しています。

表示設定と音量は現在のブラウザに保存されます。通知とシーンの進み具合は、この体験の間だけ保持されます。サウンドの再生中にブラウザのタブを切り替えると自動で一時停止し、自動では再開しません。

## 音声コマンドと DeepSeek アシスタント

左上のマイクを押すと音声コマンドが開きます。Chrome、Edge、Safari では「音声認識を開始」を押して「地図を開いて」「空間をスキャン」などと話し、「終了して実行」を押します。1 回の録音は最長約 12 秒です。初回の録音時にブラウザがマイクの許可を求めます。音声認識はブラウザが行い、ブラウザ提供元のオンラインサービスを使う場合があります。ほかのブラウザでは文字で入力するか、例のコマンドを押してください。コマンドはまずローカルのルールで照合します。

「設定 → DeepSeek アシスタント」に自分の DeepSeek API キーを入力すると、ローカルのルールで認識できない言い方や質問をアシスタントが受け取ります。アシスタントは一、二文で答え、その回答はパネルに表示され、現在の言語で読み上げられます。デモにある操作を 1 つ選んで実行することもあり、その結果はデバイスが読み上げます。リクエストは直近のやり取りと一緒にブラウザから DeepSeek へ直接送信され、料金がかかる場合があります（[公式の料金ページ](https://api-docs.deepseek.com/quick_start/pricing/)）。キーは現在のブラウザにのみ保存され、設定から削除できます。初期設定に戻してもキーは消えません。アシスタントはインターネットやリアルタイムのデータにアクセスできず、デモの場所、天気、通知はすべて模擬データです。

## キーボードショートカット

入力欄の外にフォーカスがあるとき、1 キーでアプリを開いたりビューを切り替えたりできます。

| キー | 操作 |
| --- | --- |
| `W` `A` `S` `C` `N` | 天気、サウンド、空間、カメラ、ナビを開く。もう一度押すと閉じる |
| `Shift+N` | 通知 |
| `,` | 設定 |
| `H` `D` `M` `F` | HUD の表示・非表示、ダークビュー、映像の反転、フルスクリーンの切り替え |
| `V` | 音声コマンドの開始・終了。ブラウザが音声認識に対応していない場合は音声コマンドのパネルを開く |
| `?` | すべてのショートカットの確認とカスタマイズ |
| `Esc` | 現在のパネルを閉じる |

初期設定のショートカットはすべて 1 キーで、Shift を加えるものまでです。ブラウザ、OS、ほかのアプリのグローバルショートカットは必ず ⌘、Ctrl、Alt を含むため、初期設定がそれらと競合することはありません。入力欄、ドロップダウン、ダイアログでキーを押しても反応しません。`?` を押すか、「設定 → キーボードショートカット」の「確認とカスタマイズ」から、操作ごとに新しいキーを登録したり解除したりできます。デバイスと集中モードは初期状態で未設定です。ブラウザやシステムが使う組み合わせ（⌘/Ctrl と 1 キー、⌘/Ctrl+Shift と 1 キー、Windows キーの組み合わせ、F5 などのファンクションキー）、Ctrl+Space などの入力方式の切り替え、Tab、Enter、矢印キーなどのページ操作キーは登録できません。WeChat や QQ のスクリーンショット、Alfred や Raycast の呼び出し、VoiceOver の ⌃⌥ など、よく使われるグローバルショートカットは登録できますが、それらのアプリが起動中は先に反応することがある旨を表示します。ほかの操作で使われているキーは、もう一度押すと付け替えられ、元の操作は未設定になります。

スクリーンリーダーや音声入力と干渉する場合は、設定で 1 キーのショートカットをまとめてオフにできます。Esc でパネルを閉じる操作は引き続き使えます。カスタマイズしたキーは現在のブラウザに保存され、初期設定に戻すと元に戻ります。

## オプションのビュー効果

右上の「システムメニュー → 設定 → ビューの効果」には、独立した 3 つのスイッチがあり、自動的に保存されます。

- **シーン背景**（既定でオン）：カメラを使わないとき、現在の空間シーンをアニメ調で描き、AR レイヤーを重ねて背景に表示します。空中庭園は晴れた空と積雲、尖塔のある浮島、シティウォークは夕暮れのビル群と鉄塔、空中列車で、ダークビューではそれぞれ星空とネオンの夜景になります。地面には六角形の AR グリッドが広がって光の輪が波紋のように走り、データの破片が舞い上がり、街にはスキャンラインが流れます。遠景・中景・前景は奥行きに応じてぼけ、太陽にはレンズフレアがかかります。「空間」でシーンを切り替えると背景もフェードで切り替わります。オフにすると無地のグレーに戻ります。
- **奥行きアニメーション**（既定でオフ）：マウスを動かすと、シーン背景が遠近ごとに視差で動き、空間レイヤーとフローティングウィンドウにわずかな視差と遠近感が生まれます。ウィンドウを開くとフェードインしながらピントが合い、シーン、地図、カメラの背景が少しぼけます。タッチ操作では登場アニメーションだけを残し、指の動きには追従しないため、スクロールやタップを妨げません。
- **カーブビュー**（既定でオフ）：上下の白いラインが浅い弧になり、下部の 9 つの円形アイコンが弧に沿って並びます。奥行きアニメーションとは別に、単独でオンにできます。

システムで動きを減らす設定がオンの場合、奥行きアニメーションと背景のアニメーションは止まり、静止したシーンとカーブの外観は残ります。HUD を隠したとき、デバイスのスタンバイ中、空間 AR に入ったとき、バックグラウンドに切り替えたときも奥行きアニメーションは止まります。初期設定に戻すと、シーン背景はオンに、ほかの 2 つの効果はオフになります。

## カメラをつなぐ

下部の「カメラ」アプリを開いて「カメラをオン」をクリックすると、そこで初めてブラウザが許可を求めます。カメラの映像はこのページ内にだけ表示され、アップロードされません。カメラの切り替え、設定での映像の反転、HUD を含まないカメラのスナップショットの保存ができます。許可を待っている間はキャンセルでき、カメラをオフにしたとき、デバイスのスタンバイ中、ページを離れたときにビデオトラックを解放します。

カメラには HTTPS（開発時の localhost は例外）と MediaDevices に対応したブラウザが必要です。許可が拒否された場合やデバイスが使えない場合も、シミュレーション画面は引き続き体験できます。

## 空間 AR

`immersive-ar` に対応したブラウザでは「空間 AR を準備」ボタンが表示されます。クリックして初めて Babylon と XR のコードを読み込みます。準備ができたらもう一度「空間 AR に入る」をクリックし、このユーザー操作でセッションを開始します。カメラモードに戻ることもできます。

一般的なデスクトップブラウザでは、通常はシミュレーションモードかカメラモードだけが使えます。空間 AR のデバイス対応、環境の参照空間、許可はブラウザの実際の機能によります。自動テストは実機での検証の代わりにはなりません。

## Vue サンプルの構成

シミュレーターは Vue 3.5 の `<script setup lang="ts">`、リアクティブな Props の分割代入、型付きのイベント、`defineModel`、`useTemplateRef` を使っています。エントリーはデバイスの機能を組み合わせるだけで、各アプリは Props で状態を受け取り、Events で操作を伝えます。

- `SystemBar`、`DeviceDock`、`DeviceWindow` は、システムバー、アプリの入口、フローティングウィンドウを管理します。アプリが開いていないときは空のビューを保ちます。
- `useSimulator` は、接続、シーン、スキャン、ナビ、通知を管理します。
- `useDisplaySettings` は表示設定とローカルへの保存を管理し、読み込んだ設定を検証します。
- `useSoundscape`、`useCamera`、`useXr` はブラウザのリソースを管理し、終了時に後片付けをします。
- デバイスのアプリは公開されている Augma コンポーネントを再利用し、アプリの状態、シーンのデータ、Babylon はデモプロジェクト内に留めます。
