# AR 设备模拟器

<a href="/ar/" target="_self">打开设备模拟器</a>。无需佩戴设备，也无需开启摄像头，即可体验 Augma 的空间图层和应用操作。

## 在模拟视界中探索

视界延续 [Augma 原站](https://augma.elpsy.cn/)：顶部时钟与白色横线、底部九个圆形图标。未开启摄像头时，背景是当前空间场景的分层动态画面，也可以换回原站的纯灰背景。点击应用展开悬浮窗口，再次点击或按 Escape 关闭。开启摄像头后，现实画面成为背景。

底部依次为镜像、天气、HUD 显示、声音、空间、摄像头、导航、GitHub 和组件文档。右上角系统菜单提供全屏、镜头切换、主题、设置、通知与设备控制；左上角麦克风打开[语音指令](#语音指令与-deepseek-助手)。

界面支持简体中文、English 和日本語。从文档进入时沿用文档的语言；直接打开时沿用上次的选择，首次打开则跟随浏览器语言。可在「设置 → 语言」中切换，选择会保存在当前浏览器。执行语音指令后会用当前语言朗读结果；浏览器不支持语音合成时只显示文字，也可在设置中关闭「语音播报」。


| 应用 | 可以体验的操作 |
| --- | --- |
| 天气 | 切换城市并查看示例温度，非实时天气 |
| 空间 | 切换空中庭院 / 城市漫游，扫描或取消扫描，固定 / 释放锚点，点击场景中的地点 |
| 导航 | 选择目的地、切换彩色路线、开始模拟导航，逐步推进直到抵达，或结束导航 |
| 声音 | 播放本地合成和弦、暂停、切换曲目、调整进度与音量 |
| 通知 | 查看本次体验中的操作记录，打开即标记已读，可清空记录 |
| 设置 | 语言、面板不透明度、深色视界、专注模式、镜像、语音播报、DeepSeek 助手、场景背景、景深动画、弧线视界、键盘快捷键，以及恢复默认设置 |

在系统菜单的「设备」中，可以待机、唤醒、断开和重新连接。待机或断开会停止扫描、导航、声音、摄像头与空间 AR。底部眼睛图标可以暂时收起应用和空间图层，再次点击即可恢复。

地图、地点、距离和扫描结果均为模拟数据，不代表定位、真实环境识别或实时交通。界面参考 Augma 的现实叠加图层、圆形应用控件与悬浮路线，以可交互 SVG 实现。

显示设置与音量保存在当前浏览器；通知与场景进度仅存在于本次体验中。播放声音后切换浏览器标签页会自动暂停，不会自动恢复。

## 语音指令与 DeepSeek 助手

点击左上角麦克风打开语音指令。在 Chrome、Edge 和 Safari 中点击「开始语音识别」，说出「打开地图」「扫描空间」等指令，再点击「结束并执行」；单次最长约 12 秒。首次录音时浏览器会请求麦克风权限；语音由浏览器识别，可能经由浏览器厂商的在线服务完成。其他浏览器可以输入文字或点击示例指令。指令先在本地按规则匹配。

在「设置 → DeepSeek 助手」中填写自己的 DeepSeek API Key 后，本地规则无法识别的说法和问题会交给助手：它用一两句话作答，回复显示在面板中并用当前语言朗读；也可以从演示已有的操作中选择一项执行，结果由设备播报。请求连同最近几轮对话从浏览器直接发送至 DeepSeek，调用可能产生费用，见[官方价格页](https://api-docs.deepseek.com/quick_start/pricing/)。密钥只保存在当前浏览器，可在设置中删除，恢复默认设置不会清除它。助手不能联网，也读不到实时数据；演示中的地点、天气和通知都是模拟内容。

## 键盘快捷键

焦点不在输入框时，可以用单键打开应用和切换视界：

| 按键 | 操作 |
| --- | --- |
| `W` `A` `S` `C` `N` | 打开天气、声音、空间、摄像头、导航，再按一次关闭 |
| `Shift+N` | 通知 |
| `,` | 设置 |
| `H` `D` `M` `F` | 显示或隐藏 HUD、切换深色视界、镜像画面、全屏 |
| `V` | 开始或结束语音指令；浏览器不支持语音识别时打开语音指令面板 |
| `?` | 查看与自定义全部快捷键 |
| `Esc` | 关闭当前面板 |

默认快捷键都是单键，最多加 Shift。浏览器、操作系统和其他应用的全局快捷键都带 ⌘、Ctrl 或 Alt，因此默认快捷键不会与它们冲突；在输入框、下拉选择和对话框中按键也不会触发。按 `?`，或在「设置 → 键盘快捷键」中点击「查看与自定义」，可为每项操作录入新按键或清除按键，设备与专注模式默认未设置。录入时会拒绝浏览器或系统占用的组合（⌘/Ctrl 加单键、⌘/Ctrl+Shift 加单键、Windows 键组合、F5 等功能键）、Ctrl+Space 等输入法切换键，以及 Tab、Enter、方向键等页面操作键。微信 / QQ 截图、Alfred / Raycast 唤起、VoiceOver 的 ⌃⌥ 等常见全局快捷键仍可保存，但会提示这些应用运行时可能先响应。按键已被其他操作使用时，再按一次即可改用，原操作的快捷键会被清除。

单键快捷键可在设置中整体关闭，避免与读屏或语音输入软件冲突；Esc 关闭面板不受影响。自定义按键保存在当前浏览器，恢复默认设置会一并恢复。

## 可选视界效果

右上角「系统菜单 → 设置 → 视界效果」提供三个独立开关，自动保存：

- **场景背景**（默认开启）：未开启摄像头时，以动画风格绘制当前空间场景，并叠加 AR 图层。空中庭院是晴空、积云与带尖塔的浮空岛，城市漫游是黄昏楼群、铁塔与空中列车；深色视界下分别换成星空和霓虹夜景。地面铺开六边形 AR 网格并不时扩散光环，数据碎片缓缓升起，城市中还有扫描线掠过；远景、中景和前景按景深虚化，阳光带有镜头光晕。在「空间」中切换场景时背景随之淡入；关闭后恢复纯灰背景。
- **景深动画**（默认关闭）：鼠标移动时，场景背景按远近分层视差，空间图层和浮窗产生轻微视差与透视；浮窗展开时渐显并对焦，场景、地图与摄像头背景轻微虚化。触屏保留入场动画，不跟随手指移动，便于滚动和点击。
- **弧线视界**（默认关闭）：上下白线变为浅弧形，底部九个圆形图标沿弧线排列。可单独开启，不依赖景深动画。

系统开启「减少动态效果」时暂停景深动画与背景中的动态，保留静态场景和弧线外观。隐藏 HUD、设备待机、进入空间 AR 或切到后台也会暂停景深。恢复默认设置会开启场景背景，关闭景深动画和弧线视界。

## 接入摄像头

打开底部「摄像头」应用，点击「开启摄像头」后，浏览器才会请求权限。摄像头只在当前页面显示，画面不会上传。可切换镜头，在设置中开启镜像，或保存一张不含 HUD 的摄像头快照。等待权限时可以取消；关闭摄像头、设备待机或离开页面时释放视频轨道。

摄像头需要 HTTPS（localhost 开发例外）和支持 MediaDevices 的浏览器。权限拒绝、设备不可用时仍可体验模拟界面。

## 空间 AR

支持 `immersive-ar` 的浏览器会出现「准备空间 AR」按钮。点击后才加载 Babylon 与 XR 代码；准备完成后再次点击「进入空间 AR」，由这次用户操作启动会话。可返回摄像头模式。

普通桌面浏览器通常只能使用模拟或摄像头模式。空间 AR 的设备支持、环境参考空间和权限以浏览器实际能力为准；自动化测试不能替代实机验证。

## Vue 示例结构

模拟器使用 Vue 3.5 的 `<script setup lang="ts">`、响应式 Props 解构、类型化事件、`defineModel` 和 `useTemplateRef`。入口仅组合设备功能，各应用通过 Props / Events 接收状态和发出操作。

- `SystemBar`、`DeviceDock` 和 `DeviceWindow` 管理系统栏、应用入口与浮窗；没有应用打开时保留空视界。
- `useSimulator` 管理连接、场景、扫描、导航与通知。
- `useDisplaySettings` 管理显示偏好和本地保存，并校验读取的设置。
- `useSoundscape`、`useCamera`、`useXr` 管理浏览器资源，退出时清理。
- 设备应用复用公开的 Augma 组件；业务状态、场景数据和 Babylon 留在演示工程中。
