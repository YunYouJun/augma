# macOS 界面与安装验收

- 修改 Dock 或悬浮窗时，以内容尺寸和当前窗口／屏幕可用区域决定宽度。新增固定宽度或图标数量上限，须有用户明确要求或已有产品约束；宽屏尚有空间时应允许继续扩展。
- 分开计算可见内容、阴影绘制空间和点击区域。阴影留白不挤占内容宽度，不改变可见边距，透明区域应允许点击穿透。
- 布局回归覆盖空 Dock、默认数量、超过 20 个和超过屏幕宽度的数量，并验证窄屏、宽屏、偏移显示器及浅／深色。最大宽度场景要检查真实宿主渲染尺寸、图标可见性和拖拽边界。玻璃阴影裁剪使用 README 中的真实窗口截图回归入口，不能只依赖离屏视图截图。
- 日用安装先构建到临时位置，校验签名并备份后，再退出旧实例、替换 `~/Applications/Augma.app`，从该路径启动并确认日用版只有一个实例。按完整包路径和 Bundle ID 识别进程，保留其他任务的独立验收包。临时测试使用独立 Bundle ID 和隔离偏好，结束后退出并清理注册；保留用户的 Dock 排列和设置。
