# Augma macOS demo

原生 macOS 演示窗口使用 SwiftUI 侧栏选择应用，WebKit 展示与 `apps/ar` 相同的界面。天气、声音、空间、摄像头、导航和系统应用均可从侧栏打开；在演示画面中点击应用图标，也会同步原生侧栏的选择。

点击主窗口工具栏的「沉浸模式」，界面会以透明悬浮层覆盖当前显示器的可用桌面区域。原窗口暂时隐藏，退出后恢复。空白区域默认允许点击穿透，应用面板和按钮仍可操作；右上角的原生控制条可切换应用、选择「操作桌面」让所有区域穿透，或退出沉浸模式。菜单栏中的 Augma 菜单也提供这些操作。应用面板和控制条使用失焦后仍保持模糊的原生材质。

需要 macOS 15、Node.js 24 和 pnpm。在仓库根目录运行 `pnpm mac:run` 可打包并启动；运行 `pnpm mac:verify` 可额外检查进程和演示窗口。两条命令都调用 `script/build_and_run.sh`。脚本会将 AR 站点构建为相对路径资源，与 SwiftPM 可执行文件一同放入 `apps/mac/dist/AugmaDesktopDemo.app`，界面可离线展示。

菜单栏中的 Augma 菜单可重新打开演示窗口，也保留了原有的辅助 HUD 浮窗与鼠标穿透开关。辅助 HUD 的 RealityKit 场景只在用户主动进入演示空间时创建。

主窗口工具栏和菜单栏都提供「始终置顶」开关；开启后演示窗口会显示在其他普通窗口上方，设置会在下次启动时保留。辅助 HUD 和沉浸模式的悬浮层保持各自原有的显示方式。

摄像头和 WebXR 仍取决于 WebKit 对本地页面及设备权限的支持；应用选择和模拟界面不依赖这些权限。沉浸模式的 WebView 透明背景使用 WebKit 的非公开 `_setDrawsBackground:` 方法，系统升级后需要重新验证。本地 `.app` 尚未签名或打包发布。

## 语音指令

点击界面左上角麦克风，选择「开始语音识别」，说出指令后点击「结束并执行」。也可在 App 内按 `⌘⇧V` 打开指令面板并开始录音，再按一次结束并执行；等待权限或识别结果时再次按下会取消。首次使用时，macOS 会请求麦克风和语音识别权限。语音识别由系统 Speech 框架完成：设备支持中文离线识别时优先在设备上处理，否则可能使用 Apple 在线识别服务。一次录音最多约 12 秒；切换应用或关闭指令面板会停止录音。

目前支持打开地图、扫描空间、播放或暂停声音、显示或隐藏 HUD、打开天气示例 / 通知 / 设置 / 摄像头面板、切换深色或浅色视界，以及对当前选中地点开始模拟导航、前进一步、结束导航。语音不会自行开启摄像头。识别文字会显示在面板中；也可以手动输入指令或点击示例按钮，不需要麦克风。网页演示不会请求麦克风权限。

默认只在本机按上述规则匹配指令。需要理解其他说法时，可在 App 菜单的「设置」中输入自己的 DeepSeek API Key，并打开「使用 DeepSeek 理解未匹配的指令」。密钥保存在 macOS 钥匙串，不传给内置网页；只有无法在本机匹配的指令文字会发送至 [DeepSeek Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/)。使用 `deepseek-flash` 解析为单个演示指令，返回值必须在上述操作白名单内；未匹配、格式错误或请求失败时不执行操作。DeepSeek API 需要自行申请密钥，调用可能收费，具体以[官方模型与价格页](https://api-docs.deepseek.com/quick_start/pricing/)为准。本地指令在未配置或未开启 DeepSeek 时照常可用。
