# Breathing Orbit · 呼吸环

Augma Link 的独立网页插件示例。吸气 4 秒、呼气 6 秒的圆环动画，支持开始、暂停、继续和重置，跟随系统的深浅色与减少动态效果偏好。界面提供简体中文、English 和日本語。

`BreathingOrbit.augmaplugin/` 是完整插件包，包含清单、HTML、CSS 和 JavaScript，不依赖 Augma 的原生计时模块或任何 npm 包。

## 试用

1. 在仓库根目录运行 `pnpm mac:run`，进入 **Augma Link → 插件**。
2. 在线目录加载后点击「下载并安装」。离线时可点击「离线示例 → 安装示例插件」，或用「从文件夹安装…」选择本目录中的 `BreathingOrbit.augmaplugin`；三种入口共用安装流程。
3. 安装完成后点击「启用」，再点击「打开」或「加入 Dock」。页面初始暂停，点击「开始」才开始动画。
4. 返回「管理插件」点击「停用」：所有窗口中的插件页面关闭，对应 Dock 入口移除。重新启用后可再次打开。
5. 点击「卸载…」并确认：移除 Augma 管理的安装副本和状态。仓库里的原始插件包保留，可重新安装。

启用状态在重启后恢复；插件只在打开页面时运行。首版每次打开、关闭或切换主窗口／沉浸模式都会创建新的网页会话，不保留上一次练习。

本目录是 `@augma/plugin-breathing-orbit` pnpm workspace 包，独立版本为 `1.0.0`，不发布到 npm。在仓库根目录运行 `pnpm plugins:build` 生成静态远程目录和带 SHA-256 的下载文件，`pnpm build` 会将它们纳入站点发布。

插件包格式、资源限制、分发协议与本地联调见[插件开发说明](../../docs/plugins.md)。
